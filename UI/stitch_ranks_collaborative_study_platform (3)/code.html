Cylinder Inertia

Pure Rolling Incline Acceleration

a = (g sin θ) / [1 + (Icm / MR2)] = ⅔ g sin θ

Friction Requirement for Pure Rolling

μmin = ⅓ tan θ = ⅓ tan(30°) = 0.192

Since μ = 0.25 > μmin, pure rolling is maintained!
